# 던전 크롤러 개발 일기

Claude와 같이 라이브 코딩으로 만들고 있는 브라우저 로그라이크 게임의 개발 기록이에요.
날짜와 시간은 한국 시간이고, 괄호 안 번호는 머지된 PR이에요.

- 게임: https://hucksoon.github.io/hucksoon/
- 랭킹: https://hucksoon.github.io/hucksoon/ranking.html
- 규칙 문서: [아이템](items.md) · [몬스터](monsters.md) · [경제](economy.md)

---

## 2026-10-14 (수) — 첫 삽

처음으로 게임을 만들었어요. HTML 파일 하나로 브라우저에서 바로 돌아가는 턴제 로그라이크예요.

- 방과 통로로 이루어진 던전 자동 생성
- 한 칸씩 움직이고, 몬스터에 부딪히면 공격
- 시야와 안개: 본 곳만 지도에 남아요
- 층이 깊어질수록 강해지는 몬스터, 포션, 골드, 경험치와 레벨 업

## 2026-10-15 (목) — 게임다운 게임으로

하루 동안 PR을 열 개 머지했어요. 로그인, 장비, 몬스터, 경제, 모바일 조작, 랭킹, 상점까지 한 번에 붙였어요.

### 오후 3시 · Xsolla 로그인과 클라우드 저장 (#1)
- 기본은 게스트 플레이. 이메일이나 문자 인증 코드로 계정을 연결해요
- 진행 상황을 계정에 저장해서, 다른 기기에서 로그인하면 이어서 해요
- Xsolla 비밀값이 저장소에 올라가지 않도록 `.gitignore`부터 만들었어요

### 오후 4시 · 장비 시스템과 캐시 상품 (#2)
- 장비 6부위(머리, 갑옷, 팔, 바지, 신발, 무기), 무기 3종(단검, 지팡이, 도끼), 등급 6단계, 세트 효과
- 아이템은 **시드로 만들어요**. 같은 시드면 언제 다시 만들어도 같은 아이템이라, 나중에 서버에서 진짜인지 확인할 수 있어요
- Xsolla 상품 설정 스크립트: 게임 화폐(캐시), 캐시 묶음 4종, 장비 상자. 원화와 엔화 가격도 넣었어요

### 오후 5시 · 몬스터 20종과 도감 (#3)
- 몬스터에 방어력을 넣고, 정예 몬스터와 5층마다 보스를 추가했어요
- 몬스터를 20종으로 늘리고 **황금 고블린** 추가: 공격하지 않고 도망다니다가 30턴 뒤 사라져요. 잡으면 좋은 아이템 2개
- 포션 자리에서 가끔 장비가 나와요
- 도감(B)에서 몬스터 정보와 처치 수를 볼 수 있어요

### 오후 6시 · 판매, 강화, 상점 (#4, #5)
- 버리기 대신 **팔기**: 아이템을 팔면 강화석을 받아요
- **강화** +1 ~ +10. +5부터 실패할 수 있고, 실패해도 아이템은 그대로예요
- 5층마다 **상점**이 열려요
- 몬스터를 잡으면 골드를 주고, 층이 깊을수록 골드가 많아져요. 경제 문서(economy.md)를 만들었어요

### 오후 6시 50분 · 모바일 조작과 밸런스 (#6, #7)
- 휴대폰용 터치 버튼(방향키, 포션, 가방, 도감, 재시작)
- 한 번에 다 팔기 버튼
- 골드 수입을 절반으로 줄였어요
- 주변 4칸 안에 몬스터가 있으면 계단을 못 내려가요 (실수로 도망치지 않게)
- 상점 진열을 3번까지 바꿀 수 있어요. 비용은 층마다 올라가요

### 오후 7시 20분 · 손에 맞는 조작 (#8)
- 방향키를 화면 양쪽으로 나눠서 양손 엄지로 누르게 했어요
- 위·아래 버튼을 살짝 엇갈리게 놓아 헷갈리지 않게 했어요
- 재시작(R)은 진행 중이면 한 번 더 물어봐요

### 오후 8시 · 랭킹 대시보드 (#9)
- 최고 층 랭킹과 최강 아이템 랭킹
- **개인정보 원칙**을 정했어요
  - 이메일 원본은 저장하지 않아요. 가린 형태(`ab***@...`)와 HMAC 값만 저장해요
  - 원본 확인은 긴급할 때 개발자만, 비밀 키가 있어야 가능해요
  - 개발자 계정은 랭킹에서 빼요 (계정 목록은 저장소가 아닌 서버 설정에만 있어요)

### 오후 10시 · Xsolla 상점과 결제 (#10)
- 별도 상점 페이지에서 캐시 묶음과 장비 상자를 팔아요
- Headless Checkout으로 카드 결제 화면을 직접 만들었어요 (샌드박스)
- 실제 샌드박스 결제를 해 보면서 결제 흐름을 다듬었어요

## 2026-10-16 (금) — 라이브 결제와 나만의 랭킹 서버

### 새벽 · 아이템과 몬스터 밸런스 개편 (#11)
플레이해 보고 느낀 문제를 고쳤어요.
- 강화하면 기본 능력치만 올랐는데, 이제 **+4, +6, +8, +10**마다 추가 능력치 한 줄도 올라요
- 세트 효과를 %로 오르는 좋은 능력치로 바꿨어요
- 주 능력치 개수: 일반·고급 1~2개, 레어 이상 3~4개
- 능력치마다 최소~최대 범위를 보여 주고, 최대치가 붙을 확률은 각각 20%
- 모든 수치가 최대인 아이템은 이름 앞에 **"고대"**가 붙어요
- 공격하면 데미지 숫자가 떠요. 치명타는 굵고 크게
- 층마다 몬스터가 더 강해지게 해서 포션을 쓸 일이 생기게 했어요. 포션은 최대 HP의 30%를 회복해요
- 몬스터 방어력 공식을 비율 방식으로 바꿨어요 (빼기 방식은 방어력이 너무 셌어요)
- 아이템 규칙 문서(items.md)를 만들었어요

### 오전 10시 · 라이브 결제 (#12)
- 샌드박스 결제에 문제가 없어서 **실제 결제**로 바꿨어요

### 오전 10시 반 · 층 유지와 부활
- 랭킹이나 상점을 보고 돌아오면 층이 처음부터 다시 만들어지던 문제를 고쳤어요. 지도, 몬스터, 위치가 그대로 남아요
- **부활**: 죽었을 때 50캐시로 한 판에 한 번, 그 층 처음부터 다시 시작해요 (몬스터도 다시 나와요)
- Xsolla에 부활 아이템을 추가했어요

### 오후 3시 · PHP 랭킹 서버 (#13)
- 처음엔 Cloudflare Workers로 만들었는데 가입이 막혀서, 이미 운영 중인 **우분투 Apache 서버**에 PHP 버전을 올렸어요
- 서버에 올리면서 하나씩 해결했어요
  - config.php 쉼표 빠짐 → 문법 오류
  - PHP SQLite·curl·mbstring 확장 설치
  - `.htaccess`가 동작하지 않아서 Apache 설정으로 `config.php`와 DB 폴더를 막았어요 (403 확인)
- 게임과 랭킹 페이지가 이 서버를 쓰도록 연결했어요

### 오후 4시 · 랭킹에서 장비 보기와 위조 검증 (#14)
- 랭킹에서 이름을 누르면 그 사람이 **최고 층을 세운 순간**의 능력치, 장비 6칸, 세트 효과, 최강 아이템이 보여요
- 서버가 아이템을 시드로 **직접 다시 만들어서** 확인해요. 게임이 보낸 능력치나 이름은 믿지 않아요
- 시드가 실제 게임에서 나올 수 있는 형식인지(몬스터, 포션 자리, 상점, 장비 상자)도 확인해요. 통과하지 못한 장비는 저장하지 않아요
- 배포 직후 이름이 안 눌렸는데, 브라우저가 예전 랭킹 화면을 기억하고 있었어요. 강력 새로고침으로 해결 ✅

## 2026-10-17 (토) — 같이 모이는 로비

### 새벽 · 게임 시작 전 대기 장소
- 접속하면 바로 던전이 아니라 **넓은 광장(로비)** 에서 시작해요. 가운데에 **던전 입구(▼)** 가 있고, 들어가면 모험이 시작돼요
- 같이 접속한 사람들이 광장에서 **@와 이름**으로 보이고, 움직이면 다른 사람 화면에서도 따라 움직여요
- 이름은 랭킹과 같은 가린 이름이에요 (`ab***@...`, `게스트 #xxxxxx`). 이름이 길어 겹쳐 보이는 건 2D 그래픽을 넣을 때 정리하기로 했어요
- 화면 아래 **"같이 접속한 사람들"** 목록: 로비에 있는지, 몇 층을 탐험 중인지 보여요
- 던전에서 **로비로(L)** 나올 수 있어요. 층은 떠난 그대로 기다려요. 새로고침하거나 상점에 다녀오면 있던 곳(던전)으로 돌아와요
- 쓰러진 판은 입구로 들어갈 때 부활·새로 시작 창이 떠요
- 서버: PHP 랭킹 서버에 접속자 위치를 주고받는 기능을 붙였어요 (로비에서는 1초마다, 던전에서는 10초마다). 이메일·기기 ID 원본은 저장하지 않아요

### 이어서 · 거래소와 우편함
게임의 핵심은 **아이템 파밍과 사용자끼리의 거래**라서, 로비에 거래소를 열었어요.
- 로비 왼쪽 **거래소($)**: 가방의 아이템을 골드·캐시 가격으로 올리고, 다른 사람이 사요
- **수수료**: 모든 거래에 캐시 1. 사는 사람이 가격에 더해 내요. 게임 운영 수익이에요
- **레전더리·세트**는 캐시 가격이 1 이상이어야 해요
- 캐시는 **별도 아이템 없이** 서버가 Xsolla에서 바로 차감·지급해요 (구매자 토큰으로 차감, 판매 대금은 프로젝트 API 키로 지급)
- 로비 오른쪽 **우편함(✉)**: 판매 대금, 산 아이템, 내린 아이템, **24시간이 지나 안 팔린 아이템**이 와요. 가방이 가득 차면 정리하고 받아요
- 등록·구매·가격·수수료·시간은 전부 **서버에 저장**돼요. 판매자·구매자는 가린 이름과 내부 키로만 남아요
- **복사 방지**: 서버가 아이템마다 주인을 기록해서, 판 아이템의 복사본은 다시 올릴 수 없고 랭킹에서도 인정하지 않아요
- 한계: 골드는 게임에 저장되는 값이라 서버가 잔액을 확인하지 못해요 (캐시는 Xsolla가 확인)

### 이어서 · 포탈과 입구 두 개
"재시작"을 **"포탈"** 로 바꿨어요. 이제 로비는 돌아오는 **마을**이에요.
- **포탈(P)**: 죽지 않았으면 골드·레벨·장비를 그대로 들고 마을로 돌아와요 (예전 "재시작"·"로비로"를 하나로 합침)
- 던전 입구에 **문이 두 개**: 왼쪽은 **1층부터**(같은 캐릭터, 새 지도), 오른쪽은 **포탈을 탄 층**으로 (떠난 그대로)
- 왼쪽 문으로 들어가면 기억된 포탈 층이 사라져서, 들어가기 전에 한 번 물어봐요
- 쓰러지면 **"마을에서 새로 시작"**: 골드와 레벨은 처음으로, 장비는 그대로, 1층이 아니라 마을로 와요
